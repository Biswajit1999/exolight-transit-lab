# ExoIntel-Prime Showcase

## One-line description

A browser-based exoplanet transit photometry laboratory combining locally cached archival light curves, theoretical modelling and an interactive WebGL star–planet scene.

## Try the live laboratory

**Live application:** https://biswajit1999.github.io/exolight-transit-lab/

## What makes the project useful

- connects transit light-curve morphology to star–planet geometry;
- keeps measured or locally processed photometry distinct from the theoretical model;
- demonstrates quadratic limb darkening and finite exposure-time integration;
- provides residual and out-of-transit diagnostics;
- includes optional starspot and exomoon hypothesis demonstrations with explicit scientific cautions;
- runs directly in a browser without a server or build step;
- supports teaching, public demonstrations and research communication.

## Honest scope

ExoIntel-Prime is an interactive scientific visualisation and education tool. It is not a formal professional fitting pipeline, a confirmed exomoon detector or proof of a unique orbital solution. A visual match does not replace uncertainty-weighted inference, systematics modelling, priors or independent validation.

## Suggested public post

> I have been developing ExoIntel-Prime, an open-source browser laboratory for exploring exoplanet transit photometry. It connects locally cached archival light curves with a worker-computed transit model and an interactive star–planet visualisation. The goal is to make transit depth, limb darkening, orbital geometry, residuals and hypothesis demonstrations easier to inspect without presenting the tool as a finished professional fitting pipeline. Feedback, target suggestions and scientific validation contributions are welcome.
